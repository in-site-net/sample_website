# Web Design Portfolio

A small portfolio of sample websites built to show local businesses what a custom site could look like for them, before they commit to a project.

## Files in this folder

| File | Description |
|---|---|
| `index.html` | The portfolio landing page — links to all three sample sites below. This is the link to share with prospects. |
| `kaapi-junction.html` | Sample site for a traditional filter-coffee café. Warm, story-driven, itemized menu. |
| `vellum-dental.html` | Sample site for a dental clinic. Clean, trust-focused, step-by-step visit process. |
| `forge-strength.html` | Sample site for a fitness studio. Bold, energetic, real weekly class timetable. |

All three sample sites are **self-contained** — no external files or images needed, just the HTML file itself. They're built with plain HTML/CSS (a bit of Google Fonts loaded online) so they'll open and display correctly on any device or browser.

**Note:** All business names, addresses, phone numbers, and prices in the sample sites are fictional placeholders for demo purposes only.

## How to view locally

Just double-click any `.html` file to open it in your browser. Start with `index.html` to see the full portfolio.

## How to put this online (free)

1. Go to [app.netlify.com/drop](https://app.netlify.com/drop)
2. Drag this whole folder (all 4 files together) into the upload box
3. Netlify gives you an instant live link (e.g. `https://your-name.netlify.app`)
4. Click **"Claim this site"** and sign up free so the link doesn't expire
5. Optionally rename the site URL in Netlify's site settings

Once live, share the `index.html` link with prospective clients so they can browse all three samples and tell you which style is closest to what they want.

## Using this for a real client project

When a client approves a design and you build their actual site:

1. Build their site as its own set of HTML/CSS files (or WordPress/Wix if that's the tool you're using for that project)
2. Upload it the same way via Netlify Drop (or another host) to get it live
3. Once they've purchased a domain (e.g. via Namecheap or GoDaddy), connect it to the hosted site by updating the domain's DNS settings to point to your host — Netlify's site settings has a "Domain management" section that walks through this
4. Hand over admin access / login details once final payment is received
